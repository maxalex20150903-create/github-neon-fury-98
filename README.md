# 霓虹格鬥 98 · NEON FURY

以 90 年代街機格鬥為靈感的原創瀏覽器遊戲。無須安裝或建置，開啟 `index.html` 即可遊玩。

## 遊戲內容

- 原創角色赤焰與蒼影、港灣夜景。
- 玩家對 AI，三種難度，三戰兩勝，每回合 60 秒。
- 快拳、重踢、跳躍、防禦、烈焰波與超必殺。
- 氣量、連擊、音效及手機觸控按鈕。

## 操作

| 按鍵 | 動作 |
| --- | --- |
| Enter | 開始 |
| A / D | 左右移動 |
| W | 跳躍 |
| S | 防禦 |
| J | 快拳 |
| K | 重踢 |
| L | 烈焰波，消耗 25 氣 |
| I | 超必殺，消耗 100 氣 |
| P | 暫停／繼續 |
| R | 重新挑戰 |

## 放到 GitHub Pages

將本資料夾內的 `index.html`、`.nojekyll` 與 `README.md` 放在儲存庫根目錄。這是靜態網頁，無須 npm、伺服器或 API 金鑰。

## 技術與素材

遊戲邏輯、人物及場景均由 JavaScript 與 Canvas 繪製，樣式與程式已整合在單一 HTML 中。Google Fonts 用於字型，無網路時使用系統備用字型。

本作品使用原創角色與圖像，未包含《拳皇》的官方素材。
